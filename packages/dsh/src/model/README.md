# 模型表面

`session-instructions.ts` 是稳定模型说明，只注入已经绑定 Surface 的 DSH Session。任务专用事实由 `$DSH_WORKSURFACE_VIEW_DIR/turn-brief.json` 按 Turn 提供：当前 instruction、受限输入、允许输出、payload Schema 和精确 `ws emit` argv。稳定模型契约只有四个 WorkSurface 变量和 Brief；模型不能打开、选择或切换当前绑定，也不需要 author authority、namespace、digest、cause resolution、CAS、Operation 或 transport。Host 执行材料可能被同一 OS principal 观察，授权仍以当前 Session/Turn/Surface capability 校验和 Turn 结束失效为准。模型在公共 `$DSH_WORKSURFACE_ROOT` 中用普通工具构建 `surfaces/` 与 code-first `orchestrations/<id>/artifact/`，旁侧 Registration 只声明现有 Surface binding 与 Event route；业务条件始终留在普通代码。执行进度、等待输入、模型调用失败和重试沿用该 Session 的 Turn/Step 语义。
